# 项目结构与功能边界

本项目为电子信息工程专业知识图谱与教学诊断智能体原型。当前运行说明以根目录README.md和review/agent-v5/运行协议与真实验收.md为准；历史方案中的未来计划不代表当前功能。

## 当前实现

公共图谱包含12项毕业能力、18门课程、108个知识或技能点，共138节点、285条关系。三层分别为能力、课程、知识点，考核记录以评价证据关联，不是第四层图谱节点。跨层支撑、归属与同层先修、相似、并列关系来自预先整理的演示数据。

前端支持结构拓扑和学情诊断视图、筛选搜索、展开聚焦、关联高亮及教师/学生演示身份切换。评价颜色区分红黄绿与灰色未充分评价，阶段性低分另加橙色虚线。班级及个人评价独立保存，学习进度和评价覆盖分别表示；只有课程总分时不反推知识点薄弱项。展示成绩来自预设JSON，不在页面进行真实成绩导入计算。

本地服务支持受限上下文查询、评价变化后的依赖检查与诊断更新、绑定对象和评价版本的追问、运行记录与静态成果导出。支持DeepSeek/OpenAI配置；真实外部调用与质量复核目前使用DeepSeek。成绩事实结论由程序生成，教学行动与复测建议由模型生成，模型不能直接改成绩。首批417项成果覆盖mixed_evidence场景的班级教师、DEMO001教师和DEMO001学生，每个范围138节点及总体画像，可无密钥读取。追问需要配置API。

学生使用模拟身份，无正式登录。资源推荐来自本地任务单目录；没有外部资源搜索、正式多用户权限或生产部署。已有测试验证程序与演示流程，尚不能宣称真实教学成效已得到验证。

## 尚未实现

尚未实现从培养方案或教学大纲自动构建图谱、多平台真实成绩接入、考核项到知识点的自动语义挂载、基于真实输入的通用成绩计算流水线、第四层考核观测点图谱、自动个性化学习路径规划、正式教务系统集成。先修关系可辅助排查与学习顺序说明，不等于已经建立并验证预测性预警模型；得分不能证明具体错因。

教师专业审核和真实教学试点待开展。24项真实诊断样本的4.15/5是开发助手人工复核分数，不是教师专家评分；417项生成完成不等于全量学科内容专家认证。参考文献核验和教学考核数据整合是申报中的其他模块，本仓库不提供这两套应用，其能力不可由本仓库证明。

## 目录导航

| 路径 | 用途 |
| --- | --- |
| index.html、src/、styles/、vendor/ | 前端入口、界面逻辑、样式、本地D3及许可 |
| agent/ | Python本地服务、上下文、供应商、诊断、会话和批次 |
| tools/ | 启动、数据维护、验证、导出及浏览器检查工具 |
| tests/ | 自动化测试与隔离测试服务 |
| review/personalization-v2/ | 当前运行所需的公共图谱、模拟学生、快照、建议与资源 |
| review/teaching-reference/ | 演示教学参考，非官方教材或学生作答 |
| review/model-diagnostics/ | 可独立读取的417项真实模型成果 |
| review/agent-v5/ | 当前契约、真实验收、迭代原始结果及截图 |
| review/agent-v3/、review/agent-v4/、review/data/ | 早期契约、验收与数据基线，保留历史追溯 |
| docs/ | 项目导航和当前功能边界 |
| .runtime/ | 本机运行数据库，不上传Git |

运行代码仍引用review中的数据目录，因此本次按文档索引整理，不移动这些文件。agent-v5中包含中间失败与修正记录，文件名含final或approved不代表最终质量结论；阅读时以运行协议、validation-report.json和followup-quality-review.json为准。

## 仓库上传范围

上传代码、静态演示数据、教学参考、真实模型诊断及验收材料，保留现有Git历史。模拟学生不是实际学生。申报表原件和桌面上的其他资料不复制进项目；本地密钥、环境配置、运行库、缓存与依赖目录由.gitignore排除。不为本项目擅自指定开源许可证；vendor中的D3许可继续保留。
