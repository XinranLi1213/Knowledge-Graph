# 预置图谱展示契约 v1.1.0

本契约继承此前nodes/edges三层结构，针对“直接读预制节点值”增加明确的展示快照语义。没有运行时成绩计算。

## 根对象

| 字段 | 含义 |
|---|---|
| schema_version | 契约版本；当前1.1.0 |
| metadata | 图谱版本、专业来源、班级、场景、模拟说明、时间 |
| program_plan | 改编培养目标、原方案信息和演示覆盖范围 |
| sources | 来源ID、截图路径、SHA-256或模拟来源说明 |
| course_groups | 6个模拟课程群 |
| policy | 制作数据时使用的阈值与解释口径；前端不重新执行 |
| nodes / edges | 带预置学情的节点和教学关系 |
| summary | 场景预设统计，不依赖前端成绩聚合 |

## 节点

通用字段：id、label、level、display_weight、source_refs、provenance、status、sidebar_info。

L1另有requirement_code、indicator_code、indicator_description。标签沿用截图的要求名称，具体指标描述为模拟，每项只设一个示例指标。

L2另有source_course_code（未知允许null）、credits、semester、course_nature、course_group_ids、course_objectives。课程目标包含id、title、description、knowledge_ids、ability_ids，不独立计分。

L3另有course_id、concept_id、knowledge_kind、course_group_ids。concept_id表示课程语境内概念ID；concept_family仅用于相似关系分组，不能据此合并成绩。

### status

| 字段 | 约束与语义 |
|---|---|
| achievement_rate | 0–100或null；预制归一化掌握度/上层达成估计，不是达标人数比例 |
| health_color | green/yellow/red/grey；直接读取 |
| coverage_rate | 0–1；有效评价支撑覆盖，非参评人数比例 |
| learning_state | not_started/in_progress/completed |
| grey_reason | null/not_started/no_evidence/insufficient_coverage |
| evidence_granularity | none/knowledge_assessment/knowledge_aggregate/course_total/course_aggregate |
| aggregation_basis | none/knowledge_assessment/weighted_inputs/course_total |
| sample_count / expected_count | 本次合成人数；不表示上层达标人数 |
| score_is_provisional | 覆盖率在0与1之间为true |
| score_provenance | simulated_precomputed |

灰色可能带有非空阶段性得分（例如覆盖不足50%）；因此不要把grey直接等同于null。null不是0，不补齐缺失分数。

### sidebar_info

description为说明，assessment_sources为当前场景预设考核证据清单（包含is_simulated标志），remediation_advice为教师建议数组，average_score为0–100或null。L1的average_score为null，因为能力达成估计不是原始试卷均分；应展示status.achievement_rate。

## 边

id/source/target必须引用稳定ID。relation_category为hierarchical或peer，relation_type为supports/belongs_to/prerequisite/similar/parallel；contains预留，但本批数据不用。directed由类型固定。

supports是L2→L1；belongs_to是L3→L2；先修只能连接同层且构成无环图；similar与parallel同层无向，各存一条边。聚合边aggregation_weight在(0,1]，其他边为null。相似强度另存similarity_score。

全部边有source_refs、provenance和review_status，本次都是simulated与demo_unreviewed。支持关系与先修方向并未得到学校审核。

## 离线制作约束

对每个目标，聚合入边的权重和为1。

有效覆盖 C = Σ(wᵢ × Cᵢ)。C>0时，已评价部分得分 S = Σ(wᵢ × Cᵢ × Sᵢ) / C；C=0时S=null。未知子节点的贡献项为0，但不能因此将未知节点显示为0分。

课程总分是独立评价入口：直接写课程score/coverage，不再通过其L3计算；能力可使用这些课程预设值。此时知识点缺失不使课程总分失效，也不得从总分填造知识点成绩。两个入口不会重复叠加。

本批预置数值保留6位小数，显示可取1位，审计容差0.000002。工具只用于离线制作与一致性校验，不纳入页面计算。

## 未来数据接入保留

个体知识点记录至少需要student_id、node_id、score、评价时间/周期与考核来源；课程总分记录需要student_id或班级、course_id、score、评价周期与来源。实际接入时再制定多次考核合成、缺考、补考和班级聚合策略。

LLM可生成同版本的结构数据或带base_version的变更包；预制status是评价数据的展示投影，不能让LLM凭培养方案猜测真实学生成绩。
