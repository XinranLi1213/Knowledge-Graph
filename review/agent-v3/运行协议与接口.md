# Agent运行协议与接口

这是v0.3历史协议。v0.4增加可视化API设置、无API只读限制与可分发模型成果；当前行为见[API设置与运行协议](../agent-v4/运行协议与验收.md)。

## 数据分工

v2 graph是公共结构，students是对象档案，snapshot是评价事实，recommendation是可审查的正式建议。v3新增事件、诊断产物、运行任务、对话轮次四类记录。运行库位于.runtime/agent.sqlite3，原JSON不被补测或模型修改；SQLite事务保存新快照与事件，记录保留历史。

diagnostic_artifact.publication=active表示解释通过结构、作用域与引用校验后自动可展示，不表示教师已采纳教学措施。原recommendation_update的candidate/upsert/remove与采纳流程继续独立；本版不实现正式建议发布。原预置建议与当前评价版本不一致时前端隐藏。追问答案不会自动覆盖诊断或正式建议。

## 何时算改变

新快照必须是同对象、同场景、同图谱/策略、当前revision+1。节点status各字段、学习进度依据、输入节点、证据引用、证据内容变化进入evaluation_changed。0与null不同，学习进度与评价覆盖不同；只变提交日期不形成新版本。数值74与74.0等价，无粗粒度分数舍入或隐含阈值。

分数由可信入口提供完整快照，服务校验权重聚合与画像一致性。演示补测是程序填入预定分数并确定性聚合；模型不能调用写分数工具。沿belongs_to/supports向上标记影响范围，先修/相似边不传播数值。个人补测不重写预置班均，班级快照需另行完整提交。

解释是否失效由已读事实、关系、证据、背景、资源、查询选择结果、策略和生成器版本指纹决定。revision/日期不单独使解释失效。总体重点选择也是查询依赖；出现新薄弱项会改变总体上下文。无关改变可生成重新验证记录：保留generated_against，更新validated_against，原产物留存。

重复event_id+相同请求幂等，不同请求复用ID报409。较早排队诊断被新版替代；运行中的旧任务完成后再次检查依赖，无法通过就不更新当前解释指针。失败保存任务状态，已接受事实仍可读。恢复启动时将中断的running任务重排，问答与可见节点优先于自动背景诊断。

## 模型读写与预算

默认只给目标一阶邻域；总体给12项能力及少量强弱/阶段风险项。最多32节点、64边、32证据、8资源、48000上下文字符。截取证据时给出omitted_evidence_count，不假装给全。只读工具read_node、read_neighbors、read_evidence、read_resources、compare_previous不接收学生ID和版本，绑定由服务决定。扩展上限为初始目标两跳，并受同一预算限制；不递归展开整图。

单任务最多4次模型调用（含终答）、6次工具调用、96000累计消息字符；单次HTTP超时45秒，默认最多1400输出token，可设128–4000。终答强制JSON Schema，只有explanation/cited_node_ids/cited_evidence_ids/resource_ids/limitations。未知节点、未读证据/资源、空答、拒绝、截断或超限均失败，不能写入合法产物。结构合法不代表教学判断已被事实证明，界面区分规则演示与模型解释。

服务端工具只读取固定对象的固定snapshot_ref；不能用工具修改结构、成绩或正式建议。密钥只在服务进程。资料正文、历史回答与诊断解释作为数据读取，不充当系统指令。用户追问携带本轮版本与所讨论解释ID；服务将对应解释摘要、来源、版本是否匹配一并给模型。历史仅取同对象/角色/节点最近4轮，问答期间出现新评价也不改本轮依据；下一问默认页面最新版本，旧回答标为历史。

## HTTP接口

服务仅监听127.0.0.1，默认8765端口。页面和API同源；JSON请求大小最多2MB。隐藏目录、运行库、环境文件、Python源码不经静态GET提供。当前角色是演示选择，没有正式身份验证，不能作为互联网多用户部署的鉴权边界。

共同作用域字段：subject_type=student/class、subject_id、scenario、audience=teacher/student、node_id（空表示总体）。仅开放现有3名演示学生与班级；班级仅教师视角。

| 方法与路径 | 输入/输出 |
|---|---|
| GET /api/agent/health | 可用性、rules_demo/model、配置的模型名；不返回Key |
| GET /api/agent/snapshot | 查询作用域，返回当前完整v2快照 |
| GET /api/agent/state | 查询作用域与角色/节点，返回有效/历史解释、近期任务、对话与事件 |
| POST /api/agent/diagnose | 共同字段；retry=true显式重新生成；相同待办去重 |
| POST /api/agent/ask | 共同字段、question（1–2000字符）、snapshot_ref；返回排队轮次与任务 |
| POST /api/agent/demo-update | 教师学生mixed_evidence；base_revision、event_id；依次补C05.K04=74、K05=82、K06=88 |
| POST /api/agent/snapshots | 教师；base_revision、event_id、snapshot（完整v2新快照） |

POST示例：

```json
{"subject_type":"student","subject_id":"DEMO001","scenario":"mixed_evidence","audience":"teacher","node_id":"C05","retry":false}
```

返回200表示接受请求/可读状态，不表示后台生成已完成；轮询state。输入错误400，版本或事件冲突409。后台任务的failed/superseded通过state读取。

## 启动与模型配置

```powershell
python -m pip install -r requirements.txt
python tools/serve.py
```

默认rules_demo，无外部模型费用。要使用真实模型，将.env.example复制为.env，设置AGENT_PROVIDER=openai、OPENAI_API_KEY和支持严格JSON Schema与函数工具的AGENT_MODEL，再重启。系统环境变量优先；Key与.env不提交Git。适配器当前仅实现OpenAI Chat Completions，不提供任意供应商的兼容承诺。缺少Key/模型的显式openai配置会拒绝启动；请求失败显示失败，不悄悄换规则答案。

可通过系统环境变量AGENT_PORT、AGENT_DB_PATH修改端口与数据库位置；这两个变量不从.env加载。测试使用独立临时/运行库，不污染默认演示。

结构化输出与工具定义参考[OpenAI结构化输出文档](https://platform.openai.com/docs/guides/structured-outputs)和[函数调用文档](https://platform.openai.com/docs/guides/function-calling)。本地已用模拟传输验证工具循环与终答协议，尚未发起真实模型请求。
