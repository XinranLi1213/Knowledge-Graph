# API设置与可独立浏览的模型诊断 v0.4

本轮先生成[执行方案](执行方案.md)，自审后实现。主图谱、学生名册、原始评价和预置建议JSON不变；本机更新仍在SQLite中。

## 使用

启动python tools/serve.py，进入任一演示身份，打开右下角“智能助手”→“API 设置”。当前支持DeepSeek和OpenAI，选择供应商并填写模型名称与对应API Key，点击“测试并启用”。测试发送DEMO001/C05上下文，最多4次模型调用，校验输出与引用，成功后才启用新配置。错误密钥、模型权限、限流及网络错误不会替换原配置。该设置属于当前本机服务，不属于模拟学生个人账户。v0.4.1新增供应商的参数差异见[多供应商API配置](../多供应商API配置.md)。

设置页面复用原抽屉，返回后恢复诊断与对话；没有增加主导航，没有修改画布尺寸、节点坐标或缩放。390px手机设置页不横向溢出。

密钥只在当前服务内存；提交后密码输入框清空，不回填、不进入localStorage/sessionStorage或Git。重启清除界面配置；环境变量/.env仍支持启动配置，并可留空密钥测试已有配置。断开按钮释放当前运行配置，若启动密钥仍留在.env，下次启动会再次读取。不要将启动配置的文件误认为被断开按钮删除。

配置后点击“生成诊断”或继续追问。点击节点、浏览已有内容不自动付费生成；评价变化仍按依赖生成更新。没有API时服务端拒绝新追问与重新诊断，而图谱、成绩、预置建议、已有模型结果和历史问答可读。API故障保留已有结果，不偷偷使用规则答案。事实更新使不匹配的解释标为历史，不将旧分数当作当前结论。

## 四类契约的兼容扩展

schema_version仍为3.0.0，新增字段可选，原记录继续合法。当前完整Schema位于contracts/，包括portable bundle Schema。

| 契约 | 新增信息 |
|---|---|
| evaluation_changed | 原规则不变 |
| diagnostic_artifact | facts_fingerprint、generation（供应商/模型/提示词版本/耗时/请求ID） |
| agent_run | generation、error_code；原usage继续记录模型调用次数和token |
| conversation_turn | generator；固定评价版本、所讨论产物保持不变 |

facts_fingerprint只描述输入事实与依赖，不包含当前密钥、所选模型或生成策略。generation独立记录来源。断开或换模型不使事实匹配的结果失效，升级提示词可显式重新生成。旧v3无独立事实指纹记录只按旧算法验证，无法可靠验证时显示历史，不能冒充当前有效。正在运行的任务捕获开始时的模型实例，设置变化不篡改结果来源。

## 诊断成果包

review/model-diagnostics/bundle.json保存模型产物、所依据的完整评价、必要前版与原始成功生成任务；manifest.json记录覆盖条数。UI“保存为静态成果”以及CLI导出使用同一逻辑，不写入密钥、私人问答或原始HTTP日志，也不自动上传。数据仍为演示数据，“真实模型”仅描述文本生成来源。

读取时依次检查运行库和静态包的有效结果；运行库结果失效而静态结果仍匹配时可退回静态包。对象、角色、节点、版本、Schema、加权结果、引用和事实指纹都要通过校验。模型结果缺失时明确显示暂无，不能用其他学生、班均或规则文本填充。损坏的成果包拒绝加载，不静默作为可信结果。

导出保留已有成果，不因当前运行库为空而清空已发布诊断。重新验证的产物保留原generated_against和原成功任务，不改写生成历史。静态包与当前事实版本无关的历史结果可以浏览，但标明历史版本。这里的“无API浏览”仍需要运行本地Python服务，不是直接双击HTML。

首次安装的空运行库会载入成果包随附的最新评价及必要前版，确保无密钥时图谱分数和解释依据一致。已有本机作用域不会被静态包回退或覆盖；相同评价ID/版本出现冲突事实则拒绝加载。

命令：

```powershell
python tools/model_diagnostics.py schemas
python tools/model_diagnostics.py validate
python tools/model_diagnostics.py export
python tools/model_diagnostics.py generate --max-tasks 4
```

generate从环境/.env读取密钥，不读取其他服务进程内存配置。默认依次处理DEMO001/mixed_evidence的教师总体、教师C05、学生总体、学生C05。每批最多4项，每项最多4次模型调用；已有有效模型产物跳过，只处理本批目标任务，不消费旧队列的无关付费任务。失败即停，已成功结果留在运行库，可继续生成或导出。无密钥直接拒绝，不能伪造模型成果。大范围预生成需另行确定任务清单与预算。

## HTTP扩展

- GET /api/agent/config：仅返回模型、是否配置/验证、能力、配置修订号，不返回Key。
- POST /api/agent/config/test：supplier（deepseek/openai）、model、api_key；兼容旧请求省略supplier时使用openai。密钥留空只允许沿用当前同一供应商的服务配置。新配置测试成功才启用，期间若被断开或配置替换则拒绝迟到结果。
- POST /api/agent/config/disconnect：转为只读，保留结果和会话。
- POST /api/agent/bundle/export：保存有效成果并更新覆盖清单。
- health/state包含can_read/can_ask/can_regenerate等能力；ask与显式retry在无API时返回403。

所有配置请求受本机Host及同源检查保护；密钥不在状态接口、日志或错误信息中返回。当前仍是本机演示，没有正式账户鉴权，不适合直接作为共享互联网服务部署。

## 验收与边界

本机没有OPENAI_API_KEY、AGENT_MODEL或.env，真实外部API调用、真实模型回答质量和首批真实成果未验证。静态清单如实为0，没有把模拟传输结果或规则结果提交为真实成果。

后台26项测试及前端13项回归通过；浏览器使用独立临时数据库和模拟传输，覆盖只读限制、设置、测试启用、坏密钥保留原配置、追问、成绩更新/历史回答、断开后浏览、图谱坐标/缩放、手机无溢出和无页面错误。模拟测试结果见../api-config-browser-check.json；截图见../api-settings-desktop.png、../api-settings-mobile.png和../api-readonly-result.png。

真实调用验收入口已完成。使用者填入有效密钥后，应先测试连接，再生成C05、追问、更新评价、断开验证，最后保存为静态成果并在无密钥安装中验证。这部分只有实际请求成功后才能标为已完成。
