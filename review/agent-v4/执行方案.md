# API配置与可独立浏览的模型诊断：执行方案

2026-10-30。依据已审核方案，先写本计划、自审后开发，不改原预置成绩。

1. 配置入口放在现有智能助手标题栏的“API设置”按钮。点击后在同一个抽屉内切换设置页，返回后恢复对话；不新增主导航、不挤压画布、不改变坐标或缩放。手机沿用现有抽屉宽度。设置页仅显示供应商OpenAI、模型名、密码输入框、连接状态、“测试并启用”“断开”与返回按钮。密码不回填、不进入浏览器存储；界面输入仅经同源本地服务提交。本轮配置保存在服务内存，重启后清除；环境变量/.env仍支持启动配置。提示该设置作用于当前本机服务，非模拟学生账号。
2. 增加服务端能力声明，未配置API时禁止新追问/重新生成；保留图谱、成绩、预置建议及已有模型诊断浏览。模型失败保留既有结果，不能偷偷改用规则回答。读取现有成果不得触发付费生成；首次连接测试只提交固定演示上下文，校验结构与引用，通过后才替换当前配置。
3. 沿用四类契约，兼容新增生成来源、事实指纹、任务耗时、请求追踪与错误分类。事实指纹不再依赖当前模型配置；旧v3指纹按记录格式兼容读取。生成任务捕获开始时的模型实例，设置变化不能把旧调用伪装成新模型。
4. 新增静态成果包Schema、清单、导出/校验工具与预算有限的生成工具。只导出真实模型且事实依赖匹配的产物，附带必要快照、生成记录及来源；不导出密钥、私人对话或原始HTTP日志。运行结果优先，同一作用域失效时继续查静态有效结果，最后展示明确缺失/历史状态。版本不一致不可套用当前成绩。
5. 补充有界批量生成命令：默认DEMO001/mixed_evidence、总体与C05、两种角色；默认最多4项任务、每项最多4次模型调用，可断点续做，超出清单/预算停止。没有密钥时不制作假的模型成果，清单真实记录空覆盖。
6. 单元/HTTP/浏览器验证：未配置可读且后端拒绝追问、断开后模型成果仍有效、更换模型不误判事实过期、错误密钥不替换工作配置、原始数据不变、设置页不改布局、手机无溢出、配置/接口响应无密钥泄漏。真实密钥若不可用，将真实外部调用与成果生成明确记为未验证，不冒充完成。
7. 更新README、运行协议、验收记录，保存本地Git版本。

自审：前端按钮只是能力提示，权限在服务端落实；同源检查保护配置接口；生产默认无规则追问；设置不持久化以避免新增密钥存储；本机服务级配置边界清晰。上述路径保留现有数据、版本绑定与图谱布局，允许无API用户浏览已保存的模型成果。
