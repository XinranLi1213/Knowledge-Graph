# 教学参考与核验算例

reference.json由tools/build_teaching_reference.py编写，覆盖12项能力、18门课程、108个知识点。学习目标、检查任务、复测标准是演示教学支架，不冒充学校教学大纲或教师讲义，也不代表学生真实错因。原评价事实与图谱结构不变。

agent/exercises.py另提供少量参数完整的辅导算例：C整数除法与浮点转换、二极管模型、固定偏置共射小信号分析。参考数值由程序计算，并检查共射放大区与变式条件。模型可以用它们设计或解释题目；用户要求先不给答案时，不向模型提供数值解答。它不是覆盖所有课程的题库或通用数学验证器。

参考版本参与新诊断事实指纹；修改后可使受影响诊断失效。知识点上下文包含同课兄弟节点以避免以局部信息误判全课排序。裁剪掉的证据必须显式标明数量，不能被描述为不存在。
