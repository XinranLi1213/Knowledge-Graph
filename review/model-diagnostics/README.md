# 可独立浏览的模型诊断

本目录保存经校验的静态模型成果与必要评价来源，纳入Git，供未配置API的本机安装浏览。配置与导出流程见../agent-v5/运行协议与真实验收.md。

当前bundle.json包含417项真实DeepSeek诊断：mixed_evidence下班级教师、DEMO001教师、DEMO001学生各139项。v2格式共享2份评价快照，约2.14MB；兼容原v1格式。每项保留真实生成记录、用量、策略版本及事实指纹，不含密钥或私人追问。事实结论由程序生成，教学行动与复测步骤由模型生成，开发助手24项抽查均分4.15/5，教师专家审核待进行。详细失败与补做记录见agent-v5。

有效API配置后在智能助手中生成诊断，再点“API设置 → 保存为静态成果”；或使用tools/model_diagnostics.py的受限生成/导出命令。保存到这里不代表已上传远程站点。
